# Data Directory

Pre-computed aggregate result files from all experiments in the manuscript.

These files are the outputs of the analysis scripts in `scripts/` and serve as inputs to the figure-generation pipeline. They are included here so that reviewers can inspect the numerical results without re-running the (API-dependent) experiments.

## Contents

| Path | Experiment | Trials |
|------|-----------|--------|
| `reproducibility_analysis.csv` | Schema constraint coverage (static analysis) | N/A |
| `determinism_experiment.csv` | Single-model determinism (Gemini 2.0 Flash) | 400 |
| `determinism_multimodel.csv` | Cross-model determinism (3 LLMs) | 240 |
| `codegen_hallucination.csv` | Code generation baseline (3 LLMs) | 240 |
| `ablation/invocation/` | Invocation-level ablation (3 conditions) | 720 |
| `ablation/e2e/` | End-to-end ablation (3 tasks x 3 conditions) | 270 |
| `ablation/analysis/` | Concordance metrics and statistical tests | Derived |
| `sensitivity/` | Prompt sensitivity (5 groups x 5 paraphrases) | 375 |
| `cross_system/` | Cross-system invocation comparison (5 conditions) | 1,200 |
| `e2e_benchmark/` | End-to-end execution benchmark (3 systems) | 45 |
| `dlpfc_benchmark/` | DLPFC ground-truth benchmark (3 systems) | 90 |
| `dlpfc_benchmark/ground_truth/` | Expert-annotated cortical layer labels | N/A |
| `casestudy_reproducibility/` | Case-study workflow concordance (4 models) | 160 |

## Notes

- Raw provider response checkpoints (JSONL) are excluded from this repository due to size and API dependence. They can be regenerated by running the corresponding experiment scripts; the committed CSV/TXT outputs are sufficient for numerical inspection.
- Large binary files (h5ad, spatial data) are not included. Datasets are available from the public repositories listed in the main README.
- All CSV files use UTF-8 encoding with comma delimiters.
